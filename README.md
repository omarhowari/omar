# Waraq PDF Lite (C# / Windows Forms)

PDF viewer and editor for Windows: open, save, save as, print, zoom, page navigation, rotate pages,
merge, split, add text comments, undo, thumbnails, drag-and-drop, error log in the status bar.

Rendering: PdfiumViewer (PDFium). Editing: PDFsharp 1.50.

Source files (all complete): Program.cs, MainForm.cs, PdfOps.cs, Dialogs.cs, IconFactory.cs, ErrorLog.cs.
See the setup steps in the chat message or open WaraqPdfLite/WaraqPdfLite.csproj directly in Visual Studio 2019/2022.
